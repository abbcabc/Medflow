北京协和医院五官科详细介绍
北京协和医院五官科成立于1950年代，是我国最早成立的眼耳鼻喉口腔综合专科之一。经过70余年的发展，现已成为国内顶尖的五官疾病诊疗中心和科研教学基地，在复旦大学医院管理研究所发布的《中国医院专科声誉排行榜》中，眼科、耳鼻喉科均位列全国前十。科室是博士和硕士学位授予点及博士后工作站，国家临床重点专科建设项目单位。

科室下设4个主要专业学科：眼科、耳鼻喉科、口腔科和头颈外科，开设18个特色专病门诊：白内障专病门诊、青光眼专病门诊、视网膜疾病门诊、角膜病门诊、小儿眼科门诊、眼底内科门诊、耳聋耳鸣门诊、眩晕门诊、鼻科疾病门诊、咽喉嗓音门诊、头颈肿瘤门诊、口腔颌面外科门诊、牙周病门诊、口腔修复门诊、口腔正畸门诊、口腔种植门诊、过敏性疾病门诊和睡眠呼吸障碍门诊。

临床特色与实力
科室现有开放床位150张，其中眼科60张，耳鼻喉科70张，口腔科20张。年门诊量超过35万人次，年手术量达1.5万余台。在复杂眼底病手术治疗、疑难听力障碍诊治、头颈肿瘤综合治疗、口腔颌面畸形矫正等领域处于国内领先地位。

五官科配备国际顶尖的专科设备，包括眼科手术显微镜系统、光学相干断层扫描（OCT）、眼底血管造影系统、眼内激光仪、耳鼻喉手术导航系统、听力检测设备、口腔CBCT、牙科显微镜等。科室拥有独立的眼科实验室、听力研究中心和口腔技工中心，为临床诊疗提供全方位支持。

科研教学成果
科室坚持"临床与科研并重"的发展理念，近5年来承担国家级科研项目28项，包括国家自然科学基金项目、国家重点研发计划等，累计科研经费超过3000万元。在眼底病发病机制、听觉生理病理、头颈肿瘤靶向治疗、口腔生物材料等领域取得重要突破，获得国家科技进步二等奖1项、中华医学科技奖一等奖1项、北京市科技进步奖5项。

作为北京协和医学院重要教学基地，科室承担八年制医学生、研究生、进修医师的培养工作。每年举办国家级继续教育项目6项，包括眼底病外科治疗新进展学习班、耳显微外科技术学习班、头颈肿瘤综合治疗学习班等，为全国培养了大量五官科专业人才。

人才队伍
科室现有医师86人，其中教授（主任医师）22人、副教授（副主任医师）18人、主治医师28人、住院医师18人。拥有博士生导师11人，硕士生导师15人。护理团队120人，其中主任护师3人，副主任护师9人。

科室主任钟勇教授现任中华医学会眼科学分会常务委员、中国医师协会眼科医师分会副会长。科室专家在国内外学术组织任职25人次，多人担任《中华眼科杂志》、《中华耳鼻咽喉头颈外科杂志》等核心期刊编委。

钟勇
五官科主任 眼科主任 主任医师 教授 博士研究生导师

详细介绍：

钟勇，男，主任医师，教授，五官科主任兼眼科主任，博士研究生导师。1989年毕业于中国协和医科大学，后一直在北京协和医院眼科工作。曾赴美国约翰霍普金斯大学威尔默眼科研究所、新加坡全国眼科中心进修。在复杂白内障手术治疗方面达到国际先进水平，年完成白内障手术2000余例。主持国家自然科学基金项目5项，在Ophthalmology、IOVS等国际权威期刊发表论文80余篇。现任中华医学会眼科学分会常务委员。
