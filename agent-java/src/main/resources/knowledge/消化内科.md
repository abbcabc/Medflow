北京协和医院消化内科详细介绍
北京协和医院消化内科成立于1950年代，经过近70年的建设与发展，现已成为国内消化疾病诊治领域的权威中心之一。在复旦大学医院管理研究所发布的《中国医院专科声誉排行榜》中连续多年位列消化病专科前十名。科室是国家临床重点专科建设项目单位、博士和硕士学位授予点及博士后工作站。

科室下设7个专业学组：胃肠疾病、肝病、胆胰疾病、消化内镜、炎症性肠病、消化肿瘤和消化动力，开设14个特色专病门诊：炎症性肠病专病门诊、胃食管反流病门诊、脂肪肝门诊、胰腺疾病门诊、消化道早癌门诊、肝病门诊、消化内镜诊疗门诊、胃肠动力障碍门诊、消化肿瘤门诊、幽门螺杆菌专病门诊、胆道疾病门诊、便秘专病门诊、小肠疾病门诊和消化疑难病会诊门诊。

临床特色与实力
科室现有开放床位90张，其中消化重症监护床位8张。年门诊量超过20万人次，年住院患者6000余人次，年消化内镜检查与治疗量超过4万例。在炎症性肠病综合治疗、消化道早癌内镜诊治、疑难肝病诊治、胰腺疾病介入治疗等领域处于国内领先地位。

消化内科配备国际顶尖的消化内镜设备，包括高清电子胃肠镜系统、超声内镜系统、磁控胶囊内镜、小肠镜、十二指肠镜、共聚焦激光显微内镜等。科室拥有独立的消化内镜中心、消化实验室和胃肠动力检查室，为患者提供全方位的诊疗服务。

科研教学成果
科室坚持临床与科研紧密结合，近5年来承担国家级科研项目26项，包括国家自然科学基金项目、国家重点研发计划等，累计科研经费超过2800万元。在炎症性肠病发病机制、消化道肿瘤早期诊断、肝纤维化逆转、胃肠微生态等领域取得重要研究成果，获得国家科技进步二等奖1项、中华医学科技奖二等奖2项、北京市科技进步奖4项。

作为北京协和医学院内科学消化专业所在地，科室承担八年制医学生、研究生、进修医师的培养工作，是北京市住院医师规范化培训基地和消化专科医师培训基地。每年举办国家级继续教育项目4项，包括消化内镜新技术学习班、炎症性肠病诊疗进展学习班、消化系统疑难病诊治提高班等。

人才队伍
科室现有医师42人，其中教授（主任医师）14人、副教授（副主任医师）10人、主治医师11人、住院医师7人。拥有博士生导师7人，硕士生导师9人。护理团队78人，其中主任护师1人，副主任护师6人，内镜专科护士比例达到90%以上。

科室主任杨爱明教授现任中华医学会消化病学分会副主任委员、中国医师协会消化医师分会副会长。科室专家在国内外学术组织任职22人次，多人担任《中华消化杂志》、《中华消化内镜杂志》等核心期刊副主编、编委。

专家团队
杨爱明
消化内科主任 主任医师 教授 博士研究生导师

擅长：消化内镜诊疗技术、消化道早癌诊断与治疗、胰腺疾病内镜治疗，在超声内镜引导下介入治疗方面达到国际先进水平。

详细介绍：

杨爱明，男，主任医师，教授，消化内科主任，博士研究生导师。1991年毕业于中国协和医科大学，后一直在北京协和医院消化内科工作。曾赴日本国立癌症中心、美国霍普金斯医院消化内镜中心深造。在消化道早癌的内镜诊断和治疗方面具有深厚造诣，年完成内镜下黏膜剥离术（ESD）500余例。主持国家自然科学基金项目4项，在Gastrointestinal Endoscopy、Endoscopy等国际权威期刊发表论文60余篇。现任中华医学会消化病学分会副主任委员。

钱家鸣，女，主任医师，教授，博士研究生导师。曾任北京协和医院消化内科主任。从医40余年，在炎症性肠病诊治方面达到国内领先水平，建立了国内最大的炎症性肠病诊疗中心之一。主持国家"十二五"科技支撑计划、国家自然科学基金重点项目等重大课题，获得国家科技进步二等奖1项。现任中华医学会消化病学分会名誉主任委员，《中华消化杂志》名誉总编辑。
