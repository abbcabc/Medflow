#北京协和医院骨科详细介绍
北京协和医院骨科成立于20世纪50年代，经过70余年的发展，现已成为国内顶尖的骨科疾病诊疗中心之一。科室在脊柱外科、关节外科、创伤骨科、骨肿瘤外科、运动医学等领域的诊疗水平均处于国内领先地位，是国家级重点学科、博士和硕士学位授予点及博士后工作站。

科室下设6个专业学组：脊柱外科、关节外科、创伤骨科、骨肿瘤外科、运动医学和足踝外科，开设8个特色专病门诊：颈椎病专病门诊、腰椎间盘突出症专病门诊、关节炎专病门诊、骨质疏松专病门诊、骨肿瘤专病门诊、运动损伤专病门诊、足踝疾病专病门诊和骨科康复门诊。连续多年在复旦大学医院管理研究所发布的《中国医院专科声誉排行榜》中位列骨科前三甲。

临床特色与实力
科室现有开放床位120张，年门诊量超过20万人次，年手术量达8000余例。在疑难危重病例的诊治方面经验丰富，吸引了大量来自全国各地的患者。特别是在复杂脊柱畸形矫正、人工关节置换与翻修、恶性骨肿瘤保肢治疗、严重创伤救治等方面达到国际先进水平。

骨科配备国际先进的医疗设备，包括术中三维C型臂X光机、骨科手术导航系统、关节镜系统、脊柱内镜系统、超声骨刀、骨科手术机器人等，为精准医疗提供有力保障。

科研教学成果
科室重视临床与科研相结合，近5年来承担国家级科研项目25项，包括国家自然科学基金重点项目、面上项目等，累计科研经费超过4000万元。在脊柱生物力学研究、人工关节材料研发、骨肿瘤靶向治疗、骨科组织工程等领域取得重要突破，获得国家科技进步二等奖2项、北京市科技进步一等奖3项。

作为北京协和医学院临床教学基地，科室承担八年制医学生、研究生、进修医师的培养工作，是北京市住院医师规范化培训基地。每年举办国家级继续教育项目6项，包括脊柱外科新技术学习班、关节置换高级研修班、骨科微创技术学习班等，为全国培养了大量骨科专业人才。

人才队伍
科室现有医师45人，其中教授（主任医师）15人、副教授（副主任医师）12人、主治医师10人、住院医师8人。拥有博士生导师9人，硕士生导师11人。护理团队65人，其中主任护师2人，副主任护师5人。

科室主任翁习生教授现任中华医学会骨科学分会副主任委员、中国医师协会骨科医师分会副会长。科室专家在中华医学会骨科学分会各专业学组担任组长、副组长等职务10余人次，多人担任《中华骨科杂志》、《中华关节外科杂志》等核心期刊副主编、编委。

专家团队
翁习生
骨科主任 主任医师 教授 博士研究生导师

擅长：关节外科、骨关节炎、类风湿关节炎、股骨头坏死的人工关节置换术，特别是在复杂初次关节置换及翻修手术方面具有深厚造诣。

详细介绍：

翁习生，男，主任医师，教授，骨科主任，博士研究生导师。1991年毕业于中国协和医科大学，后一直在北京协和医院骨科工作。曾赴美国哈佛医学院附属医院、德国Endo-Clinic医院进修学习。在关节疾病的诊治方面经验丰富，尤其在复杂关节置换手术方面达到国内领先水平。主持国家自然科学基金重点项目、国家重点研发计划等科研项目10余项，发表SCI论文80余篇，主编《人工关节置换术》等专著5部。

邱贵兴
中国工程院院士 主任医师 教授 博士研究生导师

擅长：脊柱外科，尤其在脊柱侧凸、脊柱后凸、脊柱肿瘤、脊柱结核等复杂脊柱疾病的诊治方面具有极高造诣。

详细介绍：

邱贵兴，中国工程院院士，我国著名脊柱外科专家。长期致力于脊柱疾病的研究与治疗，在国际上首次提出"脊柱三维矫形理论"，创立了适合中国国情的脊柱侧凸治疗体系。获得国家科技进步二等奖3项，何梁何利科技进步奖等荣誉。现任中华医学会骨科学分会名誉主任委员，《中华骨科杂志》总编辑。

赵宇
骨科副主任 主任医师 教授 博士研究生导师

擅长：脊柱畸形、脊柱退行性疾病、脊柱微创手术，在青少年特发性脊柱侧凸、退变性脊柱侧凸的诊疗方面具有丰富经验。

详细介绍：

赵宇，男，主任医师，教授，骨科副主任，博士研究生导师。2000年毕业于中国协和医科大学。曾赴美国华盛顿大学医学院、德国Schön Klinik医院访问学习。在脊柱畸形的矫治方面达到国际先进水平，年完成脊柱手术500余例。主持国家自然科学基金项目4项，在Spine、European Spine Journal等国际权威期刊发表论文60余篇。

林进
骨科副主任 主任医师 教授 博士研究生导师

擅长：关节外科、运动医学，在关节镜微创手术、肩关节疾病诊治、关节软骨损伤修复等方面具有专长。

详细介绍：

林进，女，主任医师，教授，骨科副主任，博士研究生导师。1998年毕业于北京医科大学，2005年获中国协和医科大学博士学位。曾赴美国霍普金斯医院、瑞士苏黎世大学医院进修。在关节镜微创技术方面经验丰富，年完成关节镜手术400余例。承担国家自然科学基金项目3项，发表SCI论文50余篇，获国家科技进步二等奖1项。
