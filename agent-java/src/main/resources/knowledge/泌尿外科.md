北京协和医院泌尿外科详细介绍
北京协和医院泌尿外科成立于1950年代，经过近70年的建设与发展，现已成为国内顶尖的泌尿系统疾病诊疗、科研和教学中心。在复旦大学医院管理研究所发布的《中国医院专科声誉排行榜》中连续多年位列泌尿外科前十名。科室是国家临床重点专科建设项目单位、博士和硕士学位授予点及博士后工作站。

科室下设7个专业学组：泌尿系肿瘤、结石、前列腺疾病、尿控与女性泌尿、男科、肾移植和泌尿系修复重建，开设14个特色专病门诊：前列腺癌专病门诊、肾癌门诊、膀胱癌门诊、泌尿系结石门诊、前列腺增生门诊、尿失禁门诊、女性泌尿门诊、男科门诊、肾移植随访门诊、神经源性膀胱门诊、小儿泌尿门诊、盆底康复门诊、血尿专病门诊和泌尿疑难病会诊门诊。

临床特色与实力
科室现有开放床位100张，其中肾移植监护床位8张。年门诊量超过12万人次，年住院患者5000余人次，年手术量超过6000例。在复杂泌尿系肿瘤微创治疗、结石综合防治、肾移植、前列腺疾病精准诊疗等领域处于国内领先地位。

泌尿外科配备国际先进的诊疗设备，包括达芬奇手术机器人系统、3D腹腔镜系统、输尿管软镜、经皮肾镜、前列腺激光治疗系统、尿动力学检查仪、体外冲击波碎石机等。科室拥有独立的尿动力学检查室、体外冲击波碎石中心和男科实验室。

科研教学成果
科室高度重视临床科研创新，近5年来承担国家级科研项目22项，包括国家自然科学基金项目、国家重点研发计划等，累计科研经费超过2500万元。在泌尿系肿瘤发病机制、结石成因与预防、前列腺疾病诊疗新技术、肾移植免疫耐受等领域取得重要研究成果，获得国家科技进步二等奖1项、中华医学科技奖二等奖2项、北京市科技进步奖3项。

作为北京协和医学院外科学泌尿专业所在地，科室承担八年制医学生、研究生、进修医师的培养工作，是北京市住院医师规范化培训基地和泌尿外科专科医师培训基地。每年举办国家级继续教育项目4项，包括泌尿外科微创技术学习班、前列腺疾病诊疗新进展学习班、泌尿系肿瘤多学科诊疗学习班等。

人才队伍
科室现有医师38人，其中教授（主任医师）12人、副教授（副主任医师）9人、主治医师10人、住院医师7人。拥有博士生导师6人，硕士生导师8人。护理团队75人，其中主任护师1人，副主任护师5人，造口治疗师3人。

科室主任纪志刚教授现任中华医学会泌尿外科学分会常务委员、中国医师协会泌尿外科医师分会副会长。科室专家在国内外学术组织任职18人次，多人担任《中华泌尿外科杂志》、《现代泌尿外科杂志》等核心期刊编委。

专家团队
纪志刚
泌尿外科主任 主任医师 教授 博士研究生导师

擅长：泌尿系肿瘤、肾移植、机器人手术，在复杂肾癌保肾手术和肾移植方面具有深厚造诣。

详细介绍：

纪志刚，男，主任医师，教授，泌尿外科主任，博士研究生导师。1994年毕业于中国协和医科大学，后一直在北京协和医院泌尿外科工作。曾赴美国克利夫兰医学中心、南加州大学凯克医学院深造。在肾癌微创保肾手术方面达到国际先进水平，年完成机器人辅助腹腔镜手术300余例。主持国家自然科学基金项目4项，在European Urology、Journal of Urology等国际顶尖期刊发表论文50余篇。现任中华医学会泌尿外科学分会常务委员。

李汉忠
主任医师 教授 博士研究生导师

擅长：泌尿系肿瘤、肾上腺疾病、前列腺疾病，在复杂肾上腺肿瘤手术治疗方面国内领先。

详细介绍：

李汉忠，男，主任医师，教授，博士研究生导师。曾任北京协和医院泌尿外科主任。从医40余年，在肾上腺疾病诊治方面享有盛誉，建立了国内最大的肾上腺疾病诊疗中心。在国际上首次报道多个肾上腺疾病新的临床分型，主持制定我国《肾上腺疾病诊治指南》。主持国家自然科学基金项目5项，获得国家科技进步二等奖1项。现任中华医学会泌尿外科学分会顾问。

徐涛
前列腺疾病中心主任 主任医师 教授 博士研究生导师

擅长：前列腺癌、前列腺增生、泌尿系肿瘤，在前列癌精准诊断和个体化治疗方面经验丰富。

详细介绍：

徐涛，男，主任医师，教授，前列腺疾病中心主任，博士研究生导师。1996年毕业于中国协和医科大学。在国内率先开展前列腺癌精准穿刺和微创治疗新技术，年完成前列腺手术400余例。主持国家自然科学基金项目3项，在Prostate、Urologic Oncology等国际权威期刊发表论文40余篇。现任中华医学会泌尿外科学分会前列腺疾病学组副组长。

张学斌
泌尿系结石中心主任 主任医师 教授 博士研究生导师

擅长：泌尿系结石、输尿管疾病、微创泌尿外科，在复杂结石微创治疗方面技术精湛。

详细介绍：

张学斌，男，主任医师，教授，泌尿系结石中心主任，博士研究生导师。1998年毕业于中国协和医科大学。在经皮肾镜和输尿管软镜治疗复杂肾结石方面达到国内领先水平，年完成结石手术600余例。主持国家自然科学基金项目3项，发表SCI论文30余篇。现任中华医学会泌尿外科学分会结石学组副组长。

谢燚

擅长：尿失禁、盆底功能障碍、神经源性膀胱、女性泌尿疾病，在盆底重建手术方面具有独到经验。

详细介绍：

谢燚，女，主任医师，教授，尿控与女性泌尿中心主任，博士研究生导师。1997年毕业于中国协和医科大学。在国内率先建立完善的尿动力学检查体系和盆底康复治疗体系，年完成尿控手术200余例。主持国家自然科学基金项目2项，在Neurourology and Urodynamics等国际权威期刊发表论文30余篇。现任中华医学会泌尿外科学分会尿控学组副组长。
