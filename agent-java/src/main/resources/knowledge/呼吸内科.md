北京协和医院呼吸内科详细介绍
北京协和医院呼吸内科成立于1950年代，是我国呼吸疾病诊疗、科研和教学的权威中心之一。经过近70年的建设发展，现已成为国家呼吸医学中心的核心单位，在复旦大学医院管理研究所发布的《中国医院专科声誉排行榜》中连续多年位列呼吸科前三名。科室是国家临床重点专科建设项目单位、博士和硕士学位授予点及博士后工作站。

科室下设9个专业学组：慢性气道疾病、肺部感染、呼吸危重症、间质性肺疾病、肺血管病、睡眠呼吸障碍、肺癌、胸膜疾病和呼吸治疗，开设16个特色专病门诊：哮喘专病门诊、慢阻肺专病门诊、间质性肺病门诊、肺血管病门诊、睡眠呼吸障碍门诊、肺癌精准治疗门诊、肺部感染门诊、咳嗽专病门诊、戒烟门诊、肺结节多学科门诊、呼吸康复门诊、罕见肺部疾病门诊、胸膜疾病门诊、肺移植随访门诊、呼吸治疗门诊和呼吸疑难病会诊门诊。

临床特色与实力
科室现有开放床位110张，其中呼吸重症监护病房（RICU）22张，睡眠监测床位8张。年门诊量超过16万人次，年住院患者8000余人次。在疑难间质性肺病诊治、呼吸危重症救治、肺癌个体化治疗、慢性气道疾病管理等领域处于国内领先、国际先进水平。

呼吸内科配备国际先进的医疗设备，包括电子支气管镜系统、超声支气管镜、内科胸腔镜、多导睡眠监测系统、肺功能仪、呼吸机、体外膜肺氧合（ECMO）设备等。科室拥有独立的呼吸内镜中心、肺功能室、睡眠呼吸监测中心和呼吸治疗中心。

科研教学成果
科室高度重视临床科研创新，近5年来承担国家级科研项目42项，包括国家自然科学基金重大项目、国家重点研发计划等，累计科研经费超过6000万元。在间质性肺病发病机制、肺癌耐药机制、呼吸危重症救治技术、慢性气道疾病防控策略等领域取得重大突破，获得国家科技进步二等奖2项、中华医学科技奖一等奖1项、北京市科技进步奖5项。

作为北京协和医学院内科学呼吸专业所在地，科室承担八年制医学生、研究生、进修医师的培养工作，是北京市住院医师规范化培训基地和呼吸与危重症医学专科医师培训基地。每年举办国家级继续教育项目6项，包括呼吸危重症救治高级研修班、间质性肺病诊疗进展学习班、呼吸内镜新技术学习班等。

人才队伍
科室现有医师46人，其中教授（主任医师）15人、副教授（副主任医师）11人、主治医师12人、住院医师8人。拥有博士生导师8人，硕士生导师10人。护理团队95人，其中主任护师2人，副主任护师7人，呼吸治疗师团队12人。

科室主任王孟昭教授现任中华医学会呼吸病学分会副主任委员、中国医师协会呼吸医师分会副会长。科室专家在国内外学术组织任职30余人次，多人担任《中华结核和呼吸杂志》、《中国呼吸与危重监护杂志》等核心期刊副主编、编委。

王孟昭
呼吸内科主任 主任医师 教授 博士研究生导师

详细介绍：

王孟昭，男，主任医师，教授，呼吸内科主任，博士研究生导师。1993年毕业于中国协和医科大学，后一直在北京协和医院呼吸内科工作。曾赴美国MD安德森癌症中心、哈佛大学医学院附属医院深造。在肺癌个体化治疗和耐药机制研究方面具有深厚造诣，主持多项国家级多中心临床研究。主持国家自然科学基金重点项目、国家科技重大专项等课题10余项，在Journal of Clinical Oncology、Lancet Respiratory Medicine等国际顶尖期刊发表论文100余篇。现任中华医学会呼吸病学分会副主任委员。

徐作军，男，主任医师，教授，间质性肺病中心主任，博士研究生导师。从医30余年，在间质性肺疾病诊治方面具有权威地位，建立了国内最大的间质性肺疾病诊疗中心。在国际上首次报道多个间质性肺疾病新的临床类型，主持制定我国《特发性肺纤维化诊断和治疗专家共识》。主持国家自然科学基金项目6项，获得国家科技进步二等奖1项。现任中华医学会呼吸病学分会间质性肺疾病学组组长。
