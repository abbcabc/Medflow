北京协和医院儿科详细介绍
北京协和医院儿科成立于1921年，与医院同期建立，是我国现代儿科学的发源地之一。经过百年发展，已成为集医疗、教学、科研、预防为一体的国家级儿童医学中心，在复旦大学医院管理研究所发布的《中国医院专科声誉排行榜》中连续多年位列儿科前十名。科室是儿科学博士和硕士学位授予点及博士后工作站，国家临床重点专科建设项目单位。

科室下设7个专业学组：新生儿专业、呼吸专业、消化专业、神经专业、心血管专业、血液肿瘤专业、内分泌遗传代谢专业，开设15个特色专病门诊：哮喘专病门诊、癫痫专病门诊、生长发育门诊、儿童糖尿病门诊、先天性心脏病门诊、血液肿瘤门诊、过敏性疾病门诊、儿童保健门诊、新生儿随访门诊、儿童风湿免疫门诊、儿童肾脏门诊、儿童心理行为门诊、儿童消化营养门诊、小儿妇科门诊、儿童睡眠障碍门诊。

临床特色与实力
科室现有开放床位120张，其中新生儿重症监护病房（NICU）25张，儿科重症监护病房（PICU）15张。年门诊量超过25万人次，年住院患者8000余人次。在疑难危重患儿的诊治方面具有丰富经验，特别是在罕见病、遗传代谢病、儿童肿瘤、新生儿疾病等领域处于国内领先地位。

儿科配备国际先进的医疗设备，包括新生儿多功能监护系统、儿童高频振荡呼吸机、床旁超声、脑功能监护仪、视频脑电图仪、儿童胃肠镜、支气管镜等。科室拥有独立的儿科实验室和儿童保健评估室，为患儿提供全方位的诊疗服务。

科研教学成果
科室高度重视临床与科研相结合，近5年来承担国家级科研项目32项，包括国家自然科学基金重点项目、国家科技重大专项等，累计科研经费超过3500万元。在儿童遗传代谢病、儿童肿瘤发病机制、新生儿脑损伤保护、儿童免疫缺陷病等领域取得重要研究成果，获得国家科技进步二等奖1项、中华医学科技奖二等奖2项、北京市科技进步一等奖2项。

作为北京协和医学院儿科学系所在地，科室承担八年制医学生、研究生、进修医师的培养工作，是北京市住院医师规范化培训基地。每年举办国家级继续教育项目5项，包括儿科疑难重症诊治进展学习班、新生儿危重症救治学习班、儿科遗传代谢病学习班等，为全国培养了大量儿科专业人才。

人才队伍
科室现有医师52人，其中教授（主任医师）14人、副教授（副主任医师）12人、主治医师16人、住院医师10人。拥有博士生导师8人，硕士生导师10人。护理团队98人，其中主任护师2人，副主任护师6人，90%以上护士拥有本科及以上学历。

科室主任宋红梅教授现任中华医学会儿科学分会副主任委员、中国医师协会儿科医师分会副会长。科室专家在中华医学会儿科学分会各专业学组担任组长、副组长等职务15人次，多人担任《中华儿科杂志》、《中国实用儿科杂志》等核心期刊副主编、编委。

专家团队
宋红梅
儿科主任 主任医师 教授 博士研究生导师

详细介绍：

宋红梅，女，主任医师，教授，儿科主任，博士研究生导师。1990年毕业于中国协和医科大学，后一直在北京协和医院儿科工作。曾赴美国波士顿儿童医院、英国大奥蒙德街儿童医院访问学习。在儿童风湿免疫性疾病和疑难罕见病诊治方面经验丰富，年接诊疑难病例超过千例。主持国家自然科学基金重点项目、国家重点研发计划等科研项目10余项，发表SCI论文60余篇。现任中华医学会儿科学分会副主任委员。

详细介绍：

魏珉，女，主任医师，教授，博士研究生导师。曾任北京协和医院儿科主任。从医40余年，在儿童肾脏病和风湿免疫性疾病领域贡献突出。首次在国内报道多种遗传性肾小管疾病，建立了完整的儿童肾脏病诊疗体系。获得国家科技进步二等奖、中华医学科技奖二等奖等荣誉。现任中华医学会儿科学分会名誉主任委员，《中华儿科杂志》副总编辑。

王丹华
新生儿专业主任 主任医师 教授 博士研究生导师

详细介绍：

王丹华，女，主任医师，教授，新生儿专业主任，博士研究生导师。1985年毕业于中国协和医科大学。曾赴美国费城儿童医院NICU、加拿大多伦多病童医院进修。年救治极低出生体重儿200余例，救治成功的最低出生体重儿为480克。主持国家科技支撑计划、北京市科委重大项目等课题，发表学术论文100余篇。现任中华医学会围产医学分会常务委员。

肖娟
血液肿瘤专业主任 主任医师 教授 博士研究生导师

擅长：儿童血液系统疾病、恶性肿瘤诊治，特别是在白血病、淋巴瘤、造血干细胞移植等方面具有专长。

详细介绍：

肖娟，女，主任医师，教授，血液肿瘤专业主任，博士研究生导师。1995年毕业于北京医科大学，2003年获中国协和医科大学博士学位。曾赴美国St.Jude儿童研究医院深造。在儿童白血病诊治方面达到国际先进水平，5年无病生存率达85%以上。主持国家自然科学基金项目4项，在Blood、Leukemia等国际权威期刊发表论文50余篇。现任中华医学会儿科学分会血液学组副组长。
