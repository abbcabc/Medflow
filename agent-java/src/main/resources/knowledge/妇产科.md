#北京协和医院妇产科详细介绍
北京协和医院妇产科成立于1921年，与医院同期建立，历经百年发展，已成为全国妇产科学的诊疗中心、科研基地和人才培养摇篮。科室在复旦大学医院管理研究所发布的《中国医院专科声誉排行榜》中连续十二年蝉联妇产科专科声誉第一名，是我国妇产科学的国家级重点学科、博士和硕士学位授予点及博士后工作站。

科室下设8个专业学组：普通妇科、妇科肿瘤、产科、生殖内分泌、计划生育、母胎医学、妇女保健和盆底重建外科，开设12个特色专病门诊：妇科肿瘤门诊、宫颈病变门诊、子宫内膜异位症门诊、不孕不育门诊、更年期门诊、高危妊娠门诊、产前诊断门诊、盆底功能障碍门诊、计划生育疑难病例门诊、月经病门诊、遗传咨询门诊和母乳喂养咨询门诊。

临床特色与实力
科室现有开放床位200余张，年门诊量逾30万人次，年住院患者1.5万余人次，年手术量超过1.2万台。在妇科恶性肿瘤的综合治疗、疑难危重孕产妇救治、生殖内分泌疾病诊治、盆底功能障碍性疾病康复等方面处于国内领先、国际先进水平。

妇产科配备国际顶尖的医疗设备，包括达芬奇手术机器人系统、宫腹腔镜系统、产科中央监护系统、产前诊断实验室、辅助生殖技术实验室等。科室拥有国内首个妇科肿瘤实验室和生殖内分泌实验室，为临床诊疗和科研创新提供强力支撑。

科研教学成果
科室秉承"临床与科研并重"的传统，近5年来承担国家级科研项目48项，包括国家自然科学基金重大项目、国家重点研发计划等，累计科研经费超过6000万元。在妇科肿瘤发病机制、生殖障碍疾病诊疗、母胎医学、出生缺陷防治等领域取得重大突破，获得国家科技进步二等奖3项、中华医学科技奖一等奖2项。

作为全国妇产科医师培训基地，科室承担北京协和医学院八年制医学生、研究生、进修医师的教学工作。每年举办国家级继续教育项目8项，包括妇科肿瘤学习班、产科危急重症救治学习班、生殖内分泌新进展学习班等，培养了全国80%的妇产科主任和学科带头人。

人才队伍
科室现有医师68人，其中教授（主任医师）18人、副教授（副主任医师）15人、主治医师20人、住院医师15人。拥有博士生导师12人，硕士生导师14人。护理团队132人，其中主任护师3人，副主任护师8人。

科室主任朱兰教授现任中华医学会妇产科学分会主任委员、中国医师协会妇产科医师分会副会长。郎景和院士担任中国工程院医药卫生学部主任、中华医学会妇产科学分会名誉主任委员。科室专家在国内外学术组织任职30余人次，多人担任《中华妇产科杂志》等核心期刊主编、副主编。

专家团队
郎景和
中国工程院院士 主任医师 教授 博士研究生导师

擅长：妇科肿瘤、子宫内膜异位症、女性盆底功能障碍性疾病、生殖道畸形等疑难复杂妇科疾病的诊治。

详细介绍：

郎景和，中国工程院院士，我国妇产科学领军人物。从医60余年，在妇科肿瘤、子宫内膜异位症等领域取得开创性成就。首次提出"子宫内膜异位症发病的'在位内膜决定论'"，创立了妇科手术笔记体系，主编《妇产科手术学》、《子宫内膜异位症》等经典著作。获得国家科技进步二等奖、何梁何利科技进步奖等重大奖项。现任中国医学科学院学部委员、中华医学会妇产科学分会名誉主任委员。

朱兰
妇产科主任 主任医师 教授 博士研究生导师

擅长：女性盆底功能障碍性疾病、妇科泌尿、生殖道畸形、妇科内镜手术，特别是在盆底重建手术方面具有深厚造诣。

详细介绍：

朱兰，女，主任医师，教授，妇产科主任，博士研究生导师。1986年毕业于北京医科大学，1995年获中国协和医科大学博士学位。曾赴美国克利夫兰医学中心、澳大利亚悉尼皇家妇女医院进修。在国内率先开展盆底功能障碍性疾病的基础与临床研究，建立了一套完整的诊疗规范。主持国家自然科学基金重点项目、国家科技支撑计划等课题10余项，发表SCI论文100余篇。现任中华医学会妇产科学分会主任委员。

刘欣燕
产科主任 主任医师 教授 博士研究生导师

擅长：高危妊娠管理、产前诊断、胎儿医学、产科危急重症救治，在妊娠合并症和并发症诊治方面经验丰富。

详细介绍：

刘欣燕，女，主任医师，教授，产科主任，博士研究生导师。1990年毕业于中国协和医科大学。曾赴英国伦敦国王学院医院、美国加州大学旧金山分校医学中心访问学习。在产科危急重症救治方面达到国内领先水平，年救治危重孕产妇300余例，成功率98%以上。承担国家科技支撑计划、北京市科委重大项目等科研课题，发表学术论文80余篇。

郁琦
生殖内分泌科主任 主任医师 教授 博士研究生导师

擅长：不孕不育、辅助生殖技术、月经紊乱、多囊卵巢综合征、更年期综合征等生殖内分泌疾病诊治。

详细介绍：

郁琦，男，主任医师，教授，生殖内分泌科主任，博士研究生导师。1993年毕业于中国协和医科大学。在国内率先开展辅助生殖技术，年完成试管婴儿周期5000余例，成功率保持国内领先水平。在生殖内分泌领域具有深厚造诣，主持国家自然科学基金项目6项，在Human Reproduction、Fertility and Sterility等国际权威期刊发表论文60余篇。现任中华医学会生殖医学分会副主任委员。

冷金花
妇科肿瘤科主任 主任医师 教授 博士研究生导师

擅长：妇科恶性肿瘤的综合治疗，特别是卵巢癌、宫颈癌、子宫内膜癌的根治性手术和个体化治疗。

详细介绍：

冷金花，女，主任医师，教授，妇科肿瘤科主任，博士研究生导师。1995年毕业于北京医科大学，2002年获中国协和医科大学博士学位。曾赴美国MD安德森癌症中心深造。在妇科肿瘤腹腔镜手术和达芬奇机器人手术方面技术精湛，年完成妇科肿瘤手术600余例。主持国家自然科学基金面上项目4项，发表SCI论文70余篇。现任中国抗癌协会妇科肿瘤专业委员会副主任委员。
