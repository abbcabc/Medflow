北京协和医院心血管内科详细介绍
北京协和医院心血管内科成立于1970年代，经过50余年的蓬勃发展，现已成为国内顶尖的心血管疾病诊疗、科研和教学中心。在复旦大学医院管理研究所发布的《中国医院专科声誉排行榜》中连续多年位列心血管病专科前十名。科室是国家临床重点专科建设项目单位、博士和硕士学位授予点及博士后工作站。

科室下设8个专业学组：冠心病、心律失常、心力衰竭与心肌病、高血压、结构性心脏病、心脏影像、心脏康复和心血管危重症，开设15个特色专病门诊：冠心病介入术后门诊、心律失常门诊、起搏器随访门诊、心力衰竭门诊、高血压专病门诊、肺动脉高压门诊、心肌病门诊、血脂异常门诊、心脏康复门诊、双心医学门诊、晕厥门诊、血栓栓塞门诊、妊娠合并心脏病门诊、老年心血管病门诊和心血管遗传咨询门诊。

临床特色与实力
科室现有开放床位120张，其中冠心病监护病房（CCU）25张，心脏电生理检查床位8张。年门诊量超过18万人次，年住院患者1万余人次，年介入手术量超过8000例。在复杂冠心病介入治疗、心律失常射频消融、心脏起搏与电生理、疑难心力衰竭诊治等领域处于国内领先地位。

心血管内科配备国际先进的医疗设备，包括数字减影血管造影（DSA）系统、三维电生理导航系统、血管内超声（IVUS）、光学相干断层成像（OCT）、血流储备分数（FFR）测定设备、心脏磁共振、心脏CT等。科室拥有独立的心脏导管室、心脏功能检查室和心血管实验室。

科研教学成果
科室高度重视临床科研与技术创新，近5年来承担国家级科研项目35项，包括国家自然科学基金重点项目、国家科技重大专项等，累计科研经费超过5000万元。在冠心病介入治疗技术创新、心律失常机制研究、心力衰竭分子机制、高血压靶器官保护等领域取得重要突破，获得国家科技进步二等奖2项、中华医学科技奖一等奖1项、北京市科技进步奖6项。

作为北京协和医学院内科学心血管病专业所在地，科室承担八年制医学生、研究生、进修医师的培养工作，是北京市住院医师规范化培训基地和心血管专科医师培训基地。每年举办国家级继续教育项目5项，包括冠心病介入治疗高级研修班、心脏电生理新技术学习班、心血管危重症救治进展学习班等。

人才队伍
科室现有医师48人，其中教授（主任医师）16人、副教授（副主任医师）12人、主治医师12人、住院医师8人。拥有博士生导师9人，硕士生导师11人。护理团队105人，其中主任护师2人，副主任护师8人，专科护士比例达到85%以上。

科室主任荆志成教授现任中华医学会心血管病学分会副主任委员、中国医师协会心血管内科医师分会副会长。科室专家在国内外学术组织任职28人次，多人担任《中华心血管病杂志》、《中国循环杂志》等核心期刊副主编、编委。

专家团队
荆志成
心血管内科主任 主任医师 教授 博士研究生导师

详细介绍：

荆志成，男，主任医师，教授，心血管内科主任，博士研究生导师。1994年毕业于上海医科大学，2001年获中国协和医科大学博士学位。曾赴法国巴黎第十一大学、美国哥伦比亚大学医学中心深造。在国际上首次提出多个肺动脉高压诊疗新方案，建立了国内最大的肺动脉高压诊疗中心。主持国家自然科学基金重点项目、国家科技支撑计划等重大课题10余项，在European Heart Journal、Circulation等国际顶尖期刊发表论文100余篇。现任中华医学会心血管病学分会副主任委员。
