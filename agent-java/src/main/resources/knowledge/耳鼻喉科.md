北京协和医院耳鼻喉科详细介绍
北京协和医院耳鼻喉科成立于1921年，与医院同期建立，是我国现代耳鼻咽喉头颈外科的发源地和权威诊疗中心。历经百年发展，现已成为国家临床重点专科、国家卫生健康委员会重点学科，在复旦大学医院管理研究所发布的《中国医院专科声誉排行榜》中连续多年位列耳鼻喉科前三名。科室是博士和硕士学位授予点及博士后工作站。

科室下设8个专业学组：耳科、鼻科、咽喉科、头颈外科、听力学科、嗓音医学、小儿耳鼻喉和变态反应，开设20个特色专病门诊：耳聋耳鸣门诊、眩晕门诊、人工耳蜗门诊、鼻窦炎鼻息肉门诊、过敏性鼻炎门诊、鼻颅底肿瘤门诊、嗓音疾病门诊、喉癌前病变门诊、头颈肿瘤门诊、甲状腺肿瘤门诊、鼾症门诊、小儿听力障碍门诊、咽异感症门诊、面神经疾病门诊、耳畸形门诊、嗅觉障碍门诊、艺术嗓音门诊、耳鼻喉疑难病会诊门诊、听力重建门诊和头颈修复门诊。

临床特色与实力
科室现有开放床位120张，其中重症监护床位12张。年门诊量超过25万人次，年住院患者8000余人次，年手术量超过1万台。在人工耳蜗植入、头颈肿瘤综合治疗、鼻颅底外科、喉功能重建、眩晕诊治等领域处于国内领先、国际先进水平。

耳鼻喉科配备国际顶尖的诊疗设备，包括高端手术显微镜、耳内镜系统、鼻内镜系统、喉内镜系统、手术导航系统、激光治疗系统、听力检测设备、前庭功能检查系统和嗓音分析仪。科室拥有独立的听力中心、前庭功能检查室、嗓音实验室和睡眠监测中心。

科研教学成果
科室坚持临床与科研并重，近5年来承担国家级科研项目35项，包括国家自然科学基金重点项目、国家重点研发计划等，累计科研经费超过4000万元。在听觉生理与病理、头颈肿瘤发病机制、鼻科学基础研究、前庭医学、嗓音医学等领域取得重大突破，获得国家科技进步二等奖2项、中华医学科技奖一等奖1项、北京市科技进步奖5项。

作为北京协和医学院耳鼻咽喉头颈外科学系所在地，科室承担八年制医学生、研究生、进修医师的培养工作，是北京市住院医师规范化培训基地和耳鼻喉科专科医师培训基地。每年举办国家级继续教育项目5项，包括耳显微外科技术学习班、鼻内镜外科新技术学习班、头颈肿瘤综合治疗学习班等。

人才队伍
科室现有医师48人，其中教授（主任医师）15人、副教授（副主任医师）11人、主治医师13人、住院医师9人。拥有博士生导师8人，硕士生导师10人。护理团队85人，其中主任护师2人，副主任护师7人，听力师12人，言语治疗师8人。

科室主任高志强教授现任中华医学会耳鼻咽喉头颈外科学分会副主任委员、中国医师协会耳鼻咽喉科医师分会副会长。科室专家在国内外学术组织任职25人次，多人担任《中华耳鼻咽喉头颈外科杂志》、《临床耳鼻咽喉头颈外科杂志》等核心期刊副主编、编委。

高志强
耳鼻喉科主任 耳科中心主任 主任医师 教授 博士研究生导师

详细介绍：

高志强，男，主任医师，教授，耳鼻喉科主任兼耳科中心主任，博士研究生导师。1991年毕业于中国协和医科大学，后一直在北京协和医院耳鼻喉科工作。曾赴美国House耳科研究所、德国汉诺威国际神经科学研究所深造。在人工耳蜗植入和复杂中耳手术方面具有深厚造诣，年完成耳科手术800余例，其中人工耳蜗植入200余例。主持国家自然科学基金重点项目、国家科技支撑计划等重大课题8项，在The Laryngoscope、Otology & Neurotology等国际顶尖期刊发表论文80余篇。现任中华医学会耳鼻咽喉头颈外科学分会副主任委员。
